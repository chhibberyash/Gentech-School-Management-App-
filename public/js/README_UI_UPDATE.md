# GenTech Fantastic UI — Dark / Light Mode Update

This package updates the supplied GenTech frontend UI while keeping the existing API calls, data structures, storage keys, and business logic intact.

## Included
- app.js
- api.js
- ui-director.js
- ui-hod.js
- ui-faculty.js
- ui-coordinator.js
- ui-student.js

## UI improvements
- Consistent light and dark application shells
- Theme preference persisted in localStorage (`gentech_theme`)
- Cleaner topbar, sidebar, forms and cards
- Better light-mode contrast
- Better dark-mode contrast
- Smoother hover/theme transitions
- Director dashboard visual consistency

## Run
Replace the corresponding frontend files in your existing project and run the project normally.
